# Adrie → v0 — applied production brief

This note records that the Adrie build must use the approved Preview as design authority and obey the current Lumivey image credibility rules.

Required production behavior:
- keep strategy ↔ operation as the core positioning;
- preserve technical credibility and the repaired source richness;
- keep the personal layer subtle: one meaningful Sunday-morning/nature/photography cue is enough;
- camera/photography is not a service and must not dominate;
- use supplied real Adrie photos as a curated source pool;
- prefer faithful crops of supplied real photos over AI reconstruction;
- never generate floating hands, arms, disconnected body fragments or implausible anatomy;
- if a human crop cannot remain believable, show less rather than invent anatomy;
- keep Adrie recognizable and never alter face/age/identity;
- preserve the change-case and source-backed seniority/knowledge without turning the site into a CV dump;
- only use verified contact data;
- target >85% fidelity to the approved Preview in visual, content and emotional characteristics.

This handoff is not a new creative direction. It is the production translation of the approved Adrie Preview.
