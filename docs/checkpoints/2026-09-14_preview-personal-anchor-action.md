# Checkpoint — Preview personal/professional balance

## Decision
A Lumivey Preview should normally combine a professional anchor with a personal recognition anchor on the homepage, unless Discovery explicitly rules that out.

## Why
Adrie regression showed that technically correct business interpretation can still produce a preview that feels like a generic consultant site. The missing layer was a visible translation of Adrie's calm, observing, photographic side alongside his technical credibility.

## Immediate implementation target
- Update Preview generation prompt so personal and professional anchors are both required when supported by evidence.
- Personal signals should influence image selection/composition, not only copy.
- Do not turn hobbies into services.
- Do not force the same personal device for every entrepreneur.
- Preserve source-backed factual richness such as contact data when confirmed.
- Tighten Adrie preview evaluation so a merely competent sector-specific design is not automatically PASS on specificity.

## Next test
Re-run Adrie Preview before sending anything to v0. Compare against both the June reference preview and the latest technical preview. Desired direction: a hybrid of personal calm/observation + technical assetmanagement credibility.
