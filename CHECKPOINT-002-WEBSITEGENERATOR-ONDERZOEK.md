# Lumivey Checkpoint 002 — Productieroute v0 + Preview-first

**Datum:** 11 september 2026

Dit checkpoint vervangt de eerdere onderzoekstekst rond de websitegenerator en sluit aan op Het Plan v0.4.

## Vast besluit

Lumivey gebruikt voorlopig **v0 van Vercel als voorkeurs-productiemotor** voor de echte website.

Lumivey is niet v0. v0 is vervangbaar gereedschap.

Lumivey blijft verantwoordelijk voor:
- Discovery;
- begrip en goudklompjes;
- feiten versus interpretaties;
- identiteit, verhaal, trots en motivatie;
- creatieve richting;
- artist impression / Preview;
- WoW / herkenning;
- Website Brief;
- kwaliteitscontrole en regie.

v0 is verantwoordelijk voor:
- technische websiterealisatie;
- frontend;
- responsive/mobile;
- productie-build;
- omzetting van de gevalideerde creatieve richting naar een echte website.

## Primaire flow

**Gesprek / Discovery**
→ automatisch zoveel mogelijk feiten en assets verzamelen uit gesprek, uploads, bestaande website en Firecrawl
→ begrip / goudklompjes
→ maakbaarheidstoets
→ **artist impression als afbeelding**
→ ondernemer reageert

Bij onvoldoende herkenning:
→ gesprek hervatten
→ begrip verdiepen
→ nieuwe artist impression

Bij herkenning / akkoord:
→ account aanmaken
→ reeds bekende gegevens voorinvullen
→ bevestigen / corrigeren
→ alleen ontbrekende productie-informatie aanvullen
→ Website Brief
→ Build Readiness Check
→ v0 via afgebakende adapter/API-laag
→ werkende responsive website
→ Lumivey QA
→ correctie
→ ondernemer keurt goed
→ live

## Preview is geen miniwebsite

De Preview is één visuele voorstelling van hoe Lumivey denkt dat de toekomstige website eruit moet gaan zien.

Doel:
**“Heb ik jou goed begrepen?”**

De Preview hoeft geen werkende HTML, navigatie, formulieren of responsive implementatie te bevatten. Die technische realisatie hoort bij v0.

De eigen websitegenerator verdwijnt daarom uit de primaire productflow. Bestaande generatorcode blijft alleen als leerobject/referentie en mogelijk toekomstig alternatief.

## Preview-to-Build verbeterlus

Na echte builds wordt de goedgekeurde Preview vergeleken met het resultaat van v0.

De lus leert alleen **maakbaarheid en overdrachtskwaliteit**:
- composities die v0 betrouwbaar kan realiseren;
- beeldverhoudingen en crops;
- typografie;
- responsive gedrag;
- haalbare interacties;
- instructies die v0 nodig heeft;
- patronen van mislukking of afwijking.

De lus leert **geen huisstijl** en mag creativiteit niet vernauwen.

Nieuwe regel:
**Nooit een WoW beloven die de productiemotor niet kan waarmaken.**

## Data tijdens Discovery

Discovery verzamelt niet alleen begrip, maar bouwt ook het feitelijke dossier op.

Bronnen kunnen zijn:
- gesprek;
- uploads;
- foto’s;
- documenten;
- bestaande website;
- Firecrawl;
- later relevante socials/bedrijfsprofielen.

Gegevens krijgen een status, bijvoorbeeld:
- confirmed;
- source-found;
- derived;
- uncertain;
- missing.

Na Preview-akkoord vraagt Lumivey dus niet opnieuw wat al bekend is. Het systeem toont/benut wat gevonden is, laat de ondernemer verifiëren en vult alleen gaten aan.

## Accountmoment

Accountaanmaak komt **na goedkeuring van de Preview** en vóór de betaalde productie-build.

Reden:
- Lumivey heeft dan al waarde bewezen;
- de ondernemer committeert zich aan doorgaan;
- vanaf dit punt worden echte productiekosten gemaakt;
- aanvullende/geverifieerde informatie kan aan de klantcase worden gekoppeld.

## v0 blijft onzichtbaar

De ondernemer ziet geen v0-interface en hoeft niet te weten welke productiemotor, modellen, API’s of pipelines op de achtergrond draaien.

Voor de ondernemer doet Lumivey het hele proces.

## Kenya Project

Na de basiskoppeling wordt Kenya Project de eerstvolgende rijkere end-to-end test.

Route:
**bestaande Kenya-site → volledige Firecrawl-inventaris → bronmateriaal → Lumivey ordening/interpretatie → nieuwe informatiearchitectuur → artist impression → akkoord → verificatie → Website Brief → v0 → Lumivey QA**

De oude site is bronmateriaal, geen ontwerpblauwdruk.

## Scope

Commercieel v0.1 blijft gericht op eenvoudige informatieve bedrijfswebsites.

Technisch mag Lumivey al rijkere contentsites zoals Kenya testen. Webshops komen later, ook al kan v0 technisch meer.
